# AzureKiri2

**简体中文** | [English](readme_en.md)

AzureKiri2 是一款 Android 平台上的吉里吉里2（KiriKiri2）视觉小说游戏**模拟器**，采用 Material 3 全新界面设计。

> 本项目源自 [zeas2/Kirikiroid2](https://github.com/zeas2/Kirikiroid2) 及其 [Yuri 分支（YuriSizuku/Kirikiroid2Yuri）](https://github.com/YuriSizuku/Kirikiroid2Yuri)，引擎核心能力一脉相承，在此向原作者表示感谢。原版界面多年未更新，本项目将其图形界面全面替换为现代化的 Material 3 设计，同时保持对吉里吉里2 游戏的良好兼容。

## 主要特性

### 游戏库
- **Steam 式游戏库首页**：封面网格布局，每张卡片展示封面、游戏名、累计游玩时长与「上次游玩」徽章
- **多种排序**：按上次游玩时间（默认）/ 按首字母（中文按拼音）/ 按游玩总时长
- **游玩时长统计**：自动计时——回到桌面或锁屏即暂停，回前台继续，多游戏间切换自动分段结算
- **游戏独立命名**：所有游戏的启动文件都叫 `data.xp3`？没关系，首次启动时可以为游戏命名（默认取所在文件夹名），之后随时重命名
- **封面自定义**：从游戏截图库或手机相册挑选图片作为封面

### 截图系统
- **游戏内截图**：右侧浮层菜单一键截图，直取游戏画面，存入该游戏的独立截图库
- **系统截图联动**：游戏前台时使用系统截屏（如三指下滑），自动收入当前游戏的截图库
- **截图库**：独立页面，按游戏筛选、大图查看、删除

### 界面与引擎
- **全新 Material 3 界面**：动态取色、深色模式、侧边导航，界面跟随系统壁纸自动配色（Android 12+）
- **游戏内浮层菜单**：运行中随时呼出的现代化菜单（游戏菜单、窗口管理、鼠标/触摸模式、输入法、截图、退出），也可在设置中切换回经典菜单样式
- **独立游戏设置**：每个游戏可以单独设置渲染、字体等参数，互不影响
- **XP3 封包转换/解密**：将加密的 XP3 封包转换为可直接读取的形式，启动更快、发热更小
- **丰富的引擎设置**：渲染器切换、FPS 限制、内存限制、纹理压缩、OpenGL 扩展开关、默认字体等高级选项，均支持折叠展示
- **完善的存储权限适配**：面向新版 Android 的分区存储体验

## 系统要求

- Android 7.0（API 24）及以上
- ARM64 设备

## 安装

从 [Releases](https://github.com/yuukisnow1208/AzureKiri2/releases) 页面下载最新版本的 APK，直接安装即可。

## 使用说明

1. **首次启动**：按提示授予「访问所有文件」权限（模拟器需要读取存储卡上的游戏文件）
2. **添加游戏**：在「浏览文件」中找到游戏目录或 `.xp3` 文件点击启动；也可以直接从系统文件管理器打开游戏文件。首次启动会弹出让您为游戏命名的对话框（默认取游戏所在文件夹名）
3. **游戏库**：首页即游戏库，点卡片启动游戏，长按卡片可重命名、更换封面、打开截图库、进入独立设置
4. **截图**：游戏中呼出右侧浮层菜单点「截图」，或直接使用系统截屏手势，截图自动按游戏归档
5. **更换封面**：长按游戏卡片 →「更换封面」，从截图库或手机相册选图
6. **转换/解密封包**（可选）：在抽屉「转换/解密XP3封包」中选择游戏目录执行，转换后游戏加载更快
7. **个性化**：在「设置」中可调整外观、渲染、字体等；某个游戏有特殊需求时，长按该游戏卡片进入独立设置

## 常见问题

**游戏无法识别？**
游戏需要是完整目录（含 `startup.tjs` 或 `data.xp3` 等封包），或单个 `.xp3` 文件。部分游戏依赖 `xp3filter.tjs` 解密脚本，请将其放在游戏目录中。

**可以运行加密游戏吗？**
可以。引擎内置常见解密方案；也可以使用「转换/解密XP3封包」功能将封包永久解密。

**游戏卡片显示的名字不对？**
所有游戏的启动文件都叫 `data.xp3`，模拟器默认用游戏所在文件夹名显示；长按卡片 →「重命名」即可改成您喜欢的名字。

**怎么给游戏换封面？**
先在游戏里截几张图，然后长按游戏卡片 →「更换封面」→ 从截图库选择；也可以直接从手机相册选择。

**字体显示异常？**
在设置中指定自定义字体文件（`.ttf` / `.otf`），或开启「强制使用默认字体」。

## 自行构建

```bash
git clone https://github.com/yuukisnow1208/AzureKiri2.git
cd AzureKiri2/project/android
./gradlew assembleRelease --offline
```

- 需要 JDK 17 与 Android SDK（NDK 25）；CMake 构建目录已重定向到仓库根 `build_android/`
- 签名配置见 `project/android/app/sign.properties`（可指向自己的 keystore）
- port 层（cocos2d-x）来自 [yuukisnow1208/port-cocos2d-x](https://github.com/yuukisnow1208/port-cocos2d-x)，CI 会自动获取
